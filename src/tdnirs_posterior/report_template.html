Exact-prior evaluation
Known parameters are excluded from accuracy. Comparisons use the same cases, observations and remaining unknown parameters. Absolute change is candidate minus reference; negative is better for error scores. Relative improvement is (reference minus candidate) / reference; positive is better. Raw relative-improvement fields are fractions (0.10 = 10%). A zero reference does not define a percentage improvement.

Counterfactual validation of prior values
Mask-Only retains the mask and inserts zero in normalized coordinates. It is an intervention, not a valid deployment prior. Worse performance with shuffled values alone does not establish useful use of correct values. Evidence requires paired nCRPS and energy-score improvements over both controls.
Intervention summaries


IRF interventions and paired-channel effects
DTOF, priors and initial posterior noise are held fixed. Shuffled, fixed, zero and channel-permuted IRFs test different dependencies. Zero IRF is a distribution-shift intervention, not a retrained DTOF-only model. Interpret all_shared channel permutations separately: they mainly exchange independent measurement noise.

Native posterior and numerical diagnostics
Finite samples outside training support are retained without rejection, clipping or resampling. Outside training support is not equivalent to physically impossible, and does not prove generalization. Nonfinite samples are recorded as numerical failures, not silently removed.
Numerical failure cases


Stable candidate multimodal sample distributions
Accuracy uses the complete native posterior. The oracle nearest mode uses the known test truth and is diagnostic only; it cannot replace deployment accuracy or justify deleting other modes. A candidate mode is not a physically validated equivalent solution.
